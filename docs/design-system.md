# 网页设计规范

Trend Sift 是紧凑的个人趋势面板。视觉参考 Claude、ChatGPT 的克制与留白，但使用自己的品牌与组件。
只提供浅色主题，不跟随系统切换深色。

## 色彩与材质

设计变量统一定义在 `web/src/styles/index.css` 的 `:root`，新增页面复用这些变量。

| 用途 | 色值 |
|---|---|
| 页面和卡片底色 | `#ffffff` |
| HN / GitHub 榜单标题底色 | `#faf3eb` / `#eff5f1` |
| 条目链接 | `#386e68` |
| HN 栏头文字 | `#986039` |
| 控件浅底 | `#f6f6f4` |
| 正文 | `#292927` |
| 次要文字 | `#71716a` |
| 分隔线 | `#e7e7e2` |
| 强调色 | `#58705a` |

避免大面积彩色背景、渐变、玻璃效果和装饰性阴影。以文字、细线和间距区分层级。
圆角以 6–8px 为主，榜单卡片不使用阴影。

## 字体与布局

- 使用系统无衬线字体，不依赖外部字体服务；取消装饰性大标题和侧边栏。
- 顶栏放品牌、统一日期月历、上一期／下一期和刷新；下一行放紧凑标题、搜索和排序。
- 上一期／下一期按钮也放在所有榜单之后、页脚说明之前，居中排列。
- 卡片标题区仅保留名称、条目数量、日期与 GitHub 周期切换，不展示时区或得分／评论、Stars／增长的解释性文案。
- 两张卡片按左侧 HN 日榜、右侧 GitHub 排列，GitHub 卡片顶部用分段按钮切换日／周／月。
- 760px 起两列，小于 760px 单列，HN 始终在前；DOM 与视觉阅读顺序一致。
- 页面最大宽度 1600px，桌面水平内边距 24px，卡片间距 14px。
- 卡片代表完整榜单，条目使用细线分隔，不再嵌套卡片；整页自然滚动，不设独立滚动区或分页。
- 恢复原有文字层级：原文标题／项目名为标题，正文摘要不加粗。条目标题与正文统一正常字重，以青绿色链接区分；条目标题桌面和手机为 14px；原始描述 12px，中文摘要 13px、正常字重、行高 1.65。
- GitHub 原始描述与中文摘要同时完整展示，不折叠、不截断；原始描述在前、中文摘要在后。
- GitHub 新条目名称旁显示 `NEW` 文字标签，使用浅琥珀底 `#fff4d6`、深棕字 `#8a4b08` 和细边框 `#e8c98a`；字号 11px、字重 600、高度 20px、水平内边距 6px、圆角 6px，与名称间隔 8px 并垂直居中。标签不换行，悬停说明「本站首次收录」。指标行显示 ⭐ 总星数、本日／本周／本月新增、语言和在榜天数。HN 指标使用 🔥 得分和 💬 评论。依据截至所选日期的本地快照，跨日／周／月榜按日期去重；不是连续天数，也不代表 GitHub 官方首次上榜。
- 通过缩减装饰、留白和条目间距提高密度，不依赖过小的正文字号。

## 交互与内容

- 两榜同时展示；所有榜单共享期数日期，写入 URL 的 `date`，GitHub 周期写入 `period`，支持分享与浏览器前进后退。
- 兼容旧链接的 `hnDate` / `githubDate` 参数，依次回退为共享日期。
- 顶部搜索同时过滤当前两榜的标题、描述、语言和摘要；热度排序分别按 HN 得分与 GitHub Stars。
- 日期选择器使用固定六行月历，支持切换年月；可选日期取所有来源、周期的期数日期并集（HN 内容日期加 `HN_LAG_DAYS`），无归档日期禁用。默认跟随最新归档，按钮显示「最新 · MM-DD」；选择历史日期后显示完整日期。月历顶部提供「最新归档」快捷入口，选中日期使用强调色，UTC 今天以圆点标记。上一期／下一期跳过缺失归档，到达边界禁用；支持 Escape 关闭、点击外部关闭和键盘操作。
- 同时预取三个 GitHub 周期，切换时保留日期与搜索条件，不重新请求已有结果。
- 缺少指定日期的周期展示空归档；两个卡片分别呈现加载、错误与空状态，单榜失败不影响其他榜单。
- 加载、空归档、搜索无结果、网络失败分别展示，不用模拟内容冒充真实数据。
- HN 卡片标注实际 UTC 内容日期；GitHub 展示上海时区榜单日期。共享日期表示期数：HN 查询所选日期减 `HN_LAG_DAYS` 的内容，默认 9 月 17 日这一期对应 9 月 15 日的 HN 内容。
- 中文摘要按条目取最新成功版本；历史榜单的排名和指标来自历史快照，摘要不是当日冻结版本。
- 正文作为普通文字渲染；外链只允许 HTTP/HTTPS。密钥、数据库和原始归档不提供给浏览器。
- 所有控件可键盘操作，有可见焦点、可访问名称；遵循系统减少动画设置。

后续收藏、已读、详情页面继续使用本规范。第一版尚未提供用户账户与服务端交互状态存储。
